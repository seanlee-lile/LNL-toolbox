Scratch 使用教程

    
Scratch 的每一块都代表一个明确操作。把左侧积木拖到中间的绿色插入位，右侧会显示它的输入、输出和全部参数。

    
    
      
  1. 从模板开始（可选）点击“论文范例 / 模板”打开 26 篇 Paper Recipe，或点击“新建算法”从空白流程开始。
    2. 
      
  2. 先搭数据链依次放入数据源、划分、标签/噪声、预处理、视图、角色和 Loader。后面的积木只能连接已有的输出 slot。
    3. 
      
  3. 再搭训练链把模型、优化器和 Epoch / Batch Loop 放到中间画布；进入 Batch Loop 后，绿色插入位会提示下一步。
    4. 
      
  4. 用公式组合器创建损失选中 Batch 内的插入位，点击“公式组合器”，选择 Softmax、CE、MSE、Weighted Sum 等公共操作，并绑定输入/输出 slot。
    5. 
      
  5. 检查、运行、看结果先点“检查”修复缺少的插口或参数，再点“运行结构验证”。右侧“运行结果”会显示状态、指标、产物目录和原始输出。
