运行前检查清单
  1. 数据：存在“加载数据集”，并在右侧 dataset 参数中选好数据源。
  2. 连接：每个积木的输入 slot 都由前面的积木产生，输出被后续步骤使用。
  3. 训练：模型、优化器、Loader 和 Training Loop 已连接；双模型要分别指定 model / optimizer。
  4. 参数：数字在允许范围内，路径、manifest 和外部资源真实存在。
  5. 公式：最终 loss 已连接到 backward；修改后重新运行结构检查。
  6. 运行模式：默认只做 1 epoch / 1 batch 结构验证；需要正式实验时切换为“完整运行”。
  7. 协议：validation_size=0 时不要添加 validation role，也不要在每个 epoch 做 validation。
  8. 标签：clean / trusted role 只能使用真实存在的 clean target，不能用 observed target 补齐。

如何使用 Scratch

    
    
      
  1. 左边选积木，拖到中间的绿色插入位。
    2. 
      
  2. 先从“数据”分类放入“加载数据集”；点击它后，在右侧“积木”标签的 dataset 下拉框选择数据源。
    3. 
      
  3. 中间搭算法，论文方法主要放在 Training Loop 内。
    4. 
      
  4. 点击绿色“运行”，系统会先检查结构。
    5. 
      
  5. 右侧“运行”面板可切换“结构验证”或“完整运行”；完整运行按 Recipe 的正式 epochs 和 batch 执行。
    6. 
      
  6. 红色积木表示错误，右边查看缺失输入和参数。
    7. 
      
  7. 右边“运行”标签查看真实指标、产物和日志。
